## 3. Section-anchor conventions

- **`§`-numbered sections**, up to 3-4 levels deep, used both as in-document headings and as cross-document citation targets: e.g. `§3.14.1`/`§3.14.2` (Style Guide v1.9 lines 462, 476), `§6.5` (MCP SOP v2, used as both a heading and a citation target throughout, e.g. lines 303, 312), `§9.1`/`§9.2` (Style Guide v1.9 lines 688, 698). Cross-document citation form is `"{DocumentID} §{N[.N[.N]]}"`, e.g. `"Card Schema Specification v1.8 §5.9 / §8.1"` (Naming Convention v1.17:348), `"RHACO_CMP_Specification v1.1 §2"` (Naming Convention v1.17:369), `"CMP-20260526-001 M5"` combined with a `§`-cite in the same sentence (Style Guide v1.9:683-686).
- **CMP milestone anchors** `M1`…`M8`, with sub-milestones like `M3-A`, `M3-A.1`, `M3-A.2`, `M3-pre`, `M4b`, `M4c`: Document Catalog v1.0 line 342 ("M1 (CRM acquisition) → M2 (30-day radon climate ANL) → …→ M6"); MCP SOP v2 throughout (lines 17, 414-421); Tool Reference v1.35 throughout (e.g. line 9 "dimension 10" narrator work under `M4b`).
- **Amendment anchors** `A1`, `A2`, sub-numbered `A1.2`, `A1.3`, `A1.5`, `A1.6`: filename suffix pattern `_A{N}` (Naming Convention v1.17:348); MCP SOP v2 §0 and §13 use "Amendment A1" repeatedly (lines 17, 20-21, 430-431); Tool Reference v1.35 cites sub-parts like "Amendment A1 section A1.3" and "Amendment A1 section A1.5" (line 22).
- **Drift-trigger anchors** `D1`…`D9` (MCP SOP v2 §8, lines 342-354) and **gate/contract anchors** `G1`-`G5`, `C-1`…`C-6`, `CS-1`/`CS-2`/`CS-A` (Tool Reference v1.35, narrator-build entries throughout, e.g. lines 9, 11, 12, 16, 36).
- **Phase+Step anchors that are not separately `§`-numbered**, e.g. `"Phase 1 Step 0"`, `"Phase 2 Step 6"` — these are markdown `####` headers (MCP SOP v2 §6, lines 116-266, e.g. `#### Phase 1 Step 0 — On-disk pre-flight`). A reader's jump-to-section resolver must therefore handle both `§N.N` numeric anchors and named phase/step headers that carry no `§` prefix.
- **Concrete GFM-heading-slug precedent**: `RHACO_Document_Catalog.md`'s quick-scan grid links each row to its own heading's GitHub-Flavored-Markdown slug, e.g. `[RHACO-HND-20260626-005](#rhaco-hnd-20260626-005-bayesian-credible-intervals-for-background-subtracted-excesses)` (line 65) — lowercased id+title, spaces→hyphens, punctuation stripped. This file is machine-generated by `RHACO_tool_catalog_librarian.py` (self-declared at line 2: "Generated by RHACO_tool_catalog_librarian.py"), so this is the corpus's own established jump-to-section mechanism for a rendered catalog page — a strong precedent for how a reader/jump-to-section feature should slugify headings.
- **Event-ID anchors** (distinct from section anchors but co-occurring in the same citation grammar): `EVT-069` / `E000069` first-mention-then-short-form pattern (Style Guide v1.9 §5.1, lines 546-554).
