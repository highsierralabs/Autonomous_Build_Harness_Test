# SCOPE.md -- honest scope register (PROMPT.md section 9)

Maintained from the first build commit after `CONSTRAINTS.md` / `ARCHITECTURE.md`. A row enters only when a capability or claim carries an unresolved limitation; constraints that produce no user-visible limitation stay in `CONSTRAINTS.md`. Status vocabulary: `EXCLUDED-V1` (deliberate, evidenced), `LIMITED` (works with a stated bound), `OPEN` (not yet decided), `RESOLVED` (row retained as history).
