# RHACO Fixture Reference (v1.0)

## 1. Purpose

Synthetic versioned reference document used to qualify the RHACO Corpus
Explorer probe framework's handling of the supersession shape: a
`REF`-typed document has an empty canonical id (falls back to its filename
stem as `doc_id`), and `superseded_by` links the retired version to its
replacement.

This is version 1.0, superseded by version 1.1.
